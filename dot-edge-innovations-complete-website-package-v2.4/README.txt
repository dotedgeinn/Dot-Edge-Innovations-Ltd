DOT EDGE INNOVATIONS LTD — WEBSITE PACKAGE v2.4

This package contains both the static website preview and the installable WordPress theme.

1) Preview/
   - Self-contained HTML pages for Home, About, Services, Products and Contact.
   - Open index.html in a modern browser to preview the site locally.

2) WordPress/
   - dot-edge-innovations-wordpress-theme-v2.4-motion-graphics.zip
   - In WordPress Admin, go to Appearance > Themes > Add New > Upload Theme.
   - Upload the theme ZIP and activate it when ready.

Notes:
- The static preview is for review and is not a replacement for installing the WordPress theme.
- Installing this package does not publish or modify your live website. Upload/activate only when you are ready.
- The theme ZIP and preview ZIP are included as supplied; the preview pages are self-contained HTML files.
